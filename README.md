# PermitVoice

Accessible practice for the US learner's permit knowledge test, in English and Spanish, read aloud.
Prototype. Florida is the first state. Plain HTML, CSS and JavaScript: no build step, no dependencies.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole app |
| `bank/*.json` | Question source, one file per topic |
| `bank.js` | Generated from `bank/` by `node build-bank.js`. Do not edit by hand |
| `states.js` | State outlines for "Find my state", decided on the device. Generated by `tools/build-states.js` from us-atlas (US Census boundaries) |
| `sw.js` | Offline cache. Bump `CACHE` when any file changes |
| `tools/smoke.js` | Browser test: `node tools/smoke.js .` |

## Question rules

- Every question exists in English and Spanish, with the same option order.
- `scope: "US"` only for rules that are the same in every state (MUTCD signs, signals, markings). Everything else carries the state code.
- `conf: "medium"` questions stay in `bank/` but are **not served** until a person checks them against the handbook or statute.
- State questions get a separate `ref` field in `bank.js`, so all handbook references can be removed in one step. Page numbers are `null` until checked.
- All wording is original. Nothing is copied from any state handbook.
